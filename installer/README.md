# Установка WinLock Agent (MVP)

## Что нужно на целевом ПК

- Windows 10/11 x64
- [.NET 8 Desktop Runtime (x64)](https://dotnet.microsoft.com/download/dotnet/8.0) — установщик его не ставит сам, только предупреждает, если не найден
- Права администратора для установки
- Учётная запись ребёнка должна быть **обычной (не администратор)** — это необходимое условие всей защиты, установщик это не проверяет и не может настроить за вас

## Установка

1. Скопируйте всю папку `installer` (вместе с `payload` и `WinLock-Install.exe`) на целевой ПК
2. Дважды щёлкните **`WinLock-Install.exe`**

   Windows покажет запрос UAC (подтверждение прав администратора) — согласитесь. Никакой
   консоли или PowerShell открывать не нужно.
3. В открывшемся окне нажмите **«Установить»**. Если WinLock уже стоял на этом ПК раньше,
   кнопка сама покажет **«Обновить»** — служба будет обновлена на месте, без переустановки
   и без потери привязанных телефонов родителей и текущего расписания.

Установщик:
- копирует файлы в `%ProgramFiles%\WinLock`
- регистрирует службу `WinLock Agent` (автозапуск, автоперезапуск при падении), либо, если она
  уже существует, обновляет её на месте
- создаёт `%ProgramData%\WinLock` и ограничивает доступ к нему только SYSTEM и администраторам
- открывает порт `51843/TCP` в брандмауэре
- добавляет в меню Пуск ярлык **«WinLock — Настройка»** (запускается с запросом прав администратора — обычный аккаунт ребёнка не сможет его использовать без пароля админа)
- запускает службу

## Привязка родительского приложения

1. Запустите ярлык «WinLock — Настройка» из меню Пуск (подтвердите UAC)
2. На экране появится QR-код
3. Отсканируйте его в приложении [WinLock.Android](../src/WinLock.Android) на телефоне
   родителя (тестировать протокол без телефона можно и через консольную заглушку
   [WinLock.ControllerStub](../src/WinLock.ControllerStub))

По умолчанию расписание пустое, поэтому **сразу после установки компьютер будет заблокирован** — это ожидаемо (fail-safe по умолчанию). Разблокировать/настроить расписание можно только через привязанное родительское приложение.

## Пересборка payload после изменений в коде

```bash
./build-payload.sh
```

(Можно запускать с Linux или Windows — публикация `win-x64 --self-contained false` не требует локальной Windows.)

## Удаление

Запустите `WinLock-Install.exe` ещё раз и нажмите **«Удалить WinLock»** (кнопка появляется,
когда служба уже установлена) — спросит, удалять ли заодно расписание и привязки телефонов,
и всё сделает без консоли.

## Известные ограничения MVP

- Автообнаружение ПК в сети (mDNS, `_winlock._tcp.local`) есть, но работает только в
  пределах одной локальной сети (не через гостевой Wi-Fi с изоляцией клиентов и не через
  мобильный интернет на телефоне) — это осознанное ограничение безопасности: управление
  вне локальной сети в этой версии не поддерживается. Если автообнаружение не сработало,
  остаются ручной ввод IP в профиле устройства и повторная привязка по QR.
- `DisableTaskMgr` и другие доп. меры на время блокировки — отложено на будущее.
