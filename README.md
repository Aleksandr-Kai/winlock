# WinLock

Родительский контроль экранного времени для Windows: Windows-служба ограничивает
компьютер ребёнка по расписанию и дневному лимиту, а Android-приложение на телефоне
родителя управляет им по Wi-Fi — в реальном времени и даже когда у компьютера нет сети.

## Возможности

- **Расписание + дневной лимит.** Разрешённые дни/часы и лимит минут в день, независимо
  друг от друга — вне окна или после исчерпания лимита компьютер блокируется автоматически.
- **Работает без сети.** Контроль — это локальная служба Windows, а не облачный сервис:
  блокировка/отсчёт времени не зависят от того, подключён ли телефон родителя.
- **Оффлайн-разблокировка по QR.** Если у ПК нет сети, на экране блокировки — QR-код;
  родитель сканирует его в приложении (по любой сети, хоть по мобильному интернету) и
  называет ребёнку 4-значный код, который тот вводит на ПК.
- **Управление с телефона.** Продлить время (+15/+30/+60 мин), задать точный лимит
  временным пикером, принудительно заблокировать/разблокировать, посмотреть и сохранить
  новое расписание, запросить разовый снимок экрана — всё по защищённому каналу.
- **Несколько устройств и родителей.** Один телефон может следить за несколькими ПК;
  один ПК может быть привязан к нескольким родителям одновременно.
- **Предупреждение о скором окончании времени.** Ненавязчивый тост поверх текущей
  активности (в т.ч. игр) за 15 минут до блокировки и затем каждые 5 минут.
- **Безопасность канала.** Самоподписанный сертификат ПК, пиннинг по SHA-256 отпечатку,
  переданному в QR при привязке; HMAC-SHA256 challenge-response для авторизации телефона;
  состояние на диске зашифровано через DPAPI.
- **Устойчивость к сбоям.** Если сохранённое состояние ПК повреждено и не читается,
  служба не падает и не блокирует ПК произвольно — но и не теряет это молча: делает
  резервную копию нечитаемого файла и присылает предупреждение на телефон, пока
  родитель его не подтвердит.
- **Установка без консоли.** Графический установщик с UAC-запросом «в один клик»;
  повторный запуск на уже установленной машине обновляет службу на месте, не трогая
  расписание и привязанные телефоны.

## Архитектура

```
                     Wi-Fi (WSS, self-signed cert + pinning)
 ┌────────────────────┐   HTTP (pairing) / WebSocket (control)   ┌──────────────────────┐
 │   WinLock.Service   │ ◄───────────────────────────────────────► │   WinLock.Android     │
 │  (Windows-служба)   │                                            │ (Kotlin/Compose,      │
 └─────────┬───────────┘                                            │  приложение родителя) │
           │ именованный канал (Named Pipe, NDJSON)                 └──────────────────────┘
           ▼
 ┌────────────────────┐
 │  WinLock.Agent.UI   │  ← полноэкранный экран блокировки / оффлайн-QR / инструмент привязки,
 │  (WPF, Session 0→1) │    запускается службой в активную пользовательскую сессию
 └────────────────────┘
```

- **[WinLock.Core](src/WinLock.Core)** — вся бизнес-логика без привязки к ОС: учёт
  времени (`UsageTracker`), решения о блокировке, протокол оффлайн-разблокировки,
  привязка устройств, сетевые сообщения, шифрованное хранилище состояния. Полностью
  покрыт юнит-тестами ([tests/WinLock.Core.Tests](tests/WinLock.Core.Tests)) и не требует
  Windows для сборки/тестирования.
- **[WinLock.Service](src/WinLock.Service)** — сама Windows-служба: ASP.NET Core
  (HTTP-привязка + WebSocket для телефонов), фоновый цикл проверки расписания каждые
  5 секунд, запуск экрана блокировки в активную сессию (служба работает в Session 0,
  своего рабочего стола не имеет).
- **[WinLock.Agent.UI](src/WinLock.Agent.UI)** — WPF-приложение: полноэкранный экран
  блокировки с QR для оффлайн-разблокировки, тост-предупреждение об окончании времени,
  инструмент первичной привязки телефона (запускается отдельно, с правами администратора).
- **[WinLock.Setup](src/WinLock.Setup)** — графический установщик/апдейтер (WinForms,
  self-contained exe) — устанавливает или обновляет службу без консоли и PowerShell.
- **[WinLock.Android](src/WinLock.Android)** — родительское приложение: нативный Kotlin +
  Jetpack Compose, без .NET/MAUI.
- **[WinLock.ControllerStub](src/WinLock.ControllerStub)** — консольная заглушка
  родительского приложения для сквозного тестирования протокола без реального телефона.

## Сборка и запуск

### Требования

- .NET 8 SDK — для `WinLock.Core`, `WinLock.Service`, `WinLock.Agent.UI`, `WinLock.Setup`,
  `WinLock.ControllerStub` (кросс-компиляция под `win-x64` работает и с Linux/macOS).
- JDK 17+, Android SDK/Gradle wrapper — для `WinLock.Android` (не требует Android Studio,
  достаточно `./gradlew`).

### Тесты и сборка .NET-части

```bash
dotnet test tests/WinLock.Core.Tests
dotnet build WinLock.sln -c Release
```

### Тесты и сборка Android-приложения

```bash
cd src/WinLock.Android
./gradlew testDebugUnitTest assembleDebug
```

### Сборка установщика для Windows

```bash
./installer/build-payload.sh
```

Соберёт `installer/payload/` (служба + UI, framework-dependent) и
`installer/WinLock-Install.exe` (графический установщик, self-contained). Скопируйте всю
папку `installer` на компьютер ребёнка и запустите `WinLock-Install.exe` — подробности в
[installer/README.md](installer/README.md).

## Протокол и безопасность

Привязка (pairing) происходит по QR-коду, показанному на ПК: в нём — токен, общий
секрет, отпечаток сертификата и адрес ПК. Дальше:

- **WebSocket-канал** (`/agent/ws`) — авторизация challenge-response на HMAC-SHA256,
  без передачи секрета по сети; сообщения полиморфные, с дискриминатором `$type`.
- **Оффлайн-разблокировка** — тот же принцип: QR на экране блокировки кодирует
  challenge, родитель считает его в приложении и называет ребёнку короткий (4 цифры,
  как ПИН-код банковской карты) ответный код — без интернета на самом ПК.
- **TLS pinning** — сертификат ПК самоподписанный, доверие устанавливается не через
  цепочку CA, а через точный отпечаток из QR (та же внеполосная доставка, что и у
  секрета).
- **Хранилище состояния** — `%ProgramData%\WinLock\state.json`, зашифровано через DPAPI
  (machine scope): расшифровать может только код, выполняющийся на этой же машине.
